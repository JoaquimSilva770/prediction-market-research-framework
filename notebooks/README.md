# Notebooks

All four notebooks use synthetic data.

Each notebook includes saved tables and plots for viewing on GitHub.

1. [Prediction-market signals](01_synthetic_prediction_market_signal.ipynb)
2. [Event backtest](02_synthetic_event_backtest.ipynb)
3. [Market-making skeleton](03_market_making_backtester_skeleton.ipynb)
4. [Four-case execution engine](04_multi_position_execution_backtest.ipynb): one shared modular engine applied to illustrative Tesla, Bitcoin, crude-oil and Federal Reserve case designs.

The notebooks do not import live datasets, token identifiers or realised strategy results. The four-case notebook names the economic mappings but uses deterministic generated order books throughout.
